Un refus n'est jamais une panne : l'application **protège** vos dossiers. Chaque message dit pourquoi ; voici comment en sortir.

## « Interdit » ou « Vous n'avez pas accès à cette page »

Votre profil n'a pas le **droit** pour cette page ou cette action. Ce n'est pas un défaut : demandez à l'administration d'ajuster votre profil si votre travail l'exige.

## Je ne trouve pas un dossier

- Vérifiez le **numéro** (format `1391/26`) et les **filtres** de la liste (année, chambre, statut).
- Vous ne voyez que les dossiers **de votre chambre**. Un dossier d'une autre chambre, **de mineurs** ou d'**instruction** est invisible sans le droit correspondant.
- Essayez le champ **« Rechercher un dossier »** de l'en-tête avec un nom de partie.

## Mon numéro est refusé à l'enrôlement

- **« Déjà enrôlé »** : ce numéro existe. Si c'est la même affaire, cochez **Jonction**.
- **« N'est jamais réutilisé »** : ce numéro appartenait à une affaire **annulée**.
- **« Une jonction se fait dans la même chambre »** : l'affaire visée est dans une autre chambre.
- **Format** : saisissez `numéro/année sur 2 chiffres`, par exemple `1500/26`.

## La première audience est refusée

La date est **trop proche** de l'enrôlement (art. 7). Demandez à la Présidente la **dérogation** : cochez-la avec un motif. Vérifiez aussi que la date n'est pas passée.

## Je ne peux pas publier le rôle

- Le rôle est **vide** : ajoutez au moins une affaire.
- La **salle est déjà prise** au même créneau : ouvrez le **Planning des salles** et changez la salle d'un des deux rôles.
- Un rôle existe **déjà** pour cette chambre à cette date.

## Je ne peux pas noter une suite à l'audience

- Le rôle n'est **pas publié** : publiez-le d'abord.
- **L'audience est terminée** : rouvrez la feuille pour corriger.
- Pour un **renvoi**, indiquez le **motif** et une **date de renvoi** un jour ouvré, après l'audience.

## « Il manque … » quand je marque la décision rédigée

Des champs obligatoires du modèle ne sont pas remplis : le message les **liste**. Enregistrez, complétez-les, puis recommencez.

## Je ne peux pas valider, signer ou délivrer

- **Valider** : la décision doit être complète, et **numérotée** si le réglage l'exige (demandez au greffier de la chambre).
- **Signer** : seule une décision **validée** se signe, avec une date **qui n'est pas dans le futur**.
- **Délivrer** : la décision doit être **signée**. Une **grosse** ne se délivre qu'**une fois** à la même personne.

## Le certificat de non-appel est refusé

Quatre causes possibles : un **recours** a été formé ; le **délai n'est pas encore expiré** ; la **signification** n'est pas enregistrée ; le **délai applicable n'est pas confirmé** (à faire valider dans « Délais de recours »).

## Mon compte est bloqué

Trop de mots de passe ou de codes faux : le compte est **verrouillé quelques minutes** par sécurité. Attendez, puis reconnectez-vous. Si le code par e-mail n'arrive pas, utilisez un **code de secours**. Sans code ni accès : contactez l'administration.

## Mon écran s'est verrouillé

C'est le **verrouillage après inactivité**. Ressaisissez votre mot de passe. Trop d'erreurs ferment la session : reconnectez-vous normalement.

## Mon fichier est refusé

Seuls les **vrais PDF et vraies images** sont acceptés (JPG, PNG, WebP), pas plus de **vingt à la fois**, et sous la **taille maximale**. Un seul fichier refusé fait refuser **tout le lot** : retirez-le et recommencez. Un fichier déjà déposé (même contenu) est ignoré.

## Une date est refusée

Pour tout ce qui est **fait** (dépôt, réception, signature, remise, mandat), la date **ne peut pas être dans le futur**. Les dates doivent aussi être **cohérentes entre elles** (une clôture ne précède pas une réception). Les dates de **renvoi** doivent tomber un **jour ouvré**.

## Je ne peux pas modifier ou supprimer

Certains éléments sont **figés** par conception : une décision validée, un rôle publié, une mise en état clôturée, une séance tenue, une requête traitée, un journal. Pour un rôle, **rouvrez-le** ; pour une décision, faites une **correction** (avec motif) ; sinon c'est définitif.

## L'écran est lent ou une liste semble vide

Les longues listes s'affichent **20 lignes par page** et chargent la suite à la demande : attendez une seconde, ou changez de page. Vérifiez vos **filtres** (une pastille de filtre active peut masquer des lignes).
